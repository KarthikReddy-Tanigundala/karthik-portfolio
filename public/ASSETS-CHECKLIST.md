# Assets Checklist

Drop these files into `/public/` before deploying.

## Required (site won't fully work without)

- [ ] **Karthik-Reddy-Resume.pdf**
  - One canonical resume — your strongest, most confident Stream 1 version
  - File name must match exactly (case-sensitive on Linux/Vercel)
  - Location: `/public/Karthik-Reddy-Resume.pdf`
  - Linked from: Hero "Resume" button + Nav "Resume ↓"
  - Tip: use the Stream 1 HTML resume template from your KB Project, export to PDF via browser print, save here

## Optional (for future polish)

- [ ] **healthcare-dashboard-screenshot.png** (when ready)
  - Recommended size: 1600×1000px
  - Location: `/public/healthcare-dashboard-screenshot.png`
  - Will be used in the Healthcare Analytics project modal
  - Once added, edit `lib/projects.ts` → add `image` field to the project

- [ ] **og-fallback.png** (only if the auto-generated OG image fails on some platforms)
  - The site auto-generates an OG image at `/opengraph-image`
  - 99% of the time this works perfectly
  - Only override if you need a custom design

## Not needed

- ❌ Favicon — auto-generated by `app/icon.tsx`
- ❌ Headshot photo — site is designed without one (decision confirmed)
- ❌ Background videos / hero images — design is type-led, not image-led

## After adding any asset

```bash
git add public/
git commit -m "add: resume PDF"
git push
```

Vercel auto-deploys within 60 seconds.
